# Security Policy

## Supported Versions

Only the latest release version on the `main` branch is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | Yes                |
| < 1.0.0 | No                 |

## Reporting a Vulnerability

If you discover a security vulnerability within FitRepacks Library, please follow these steps:

1. Do not report security vulnerabilities through public GitHub issues or discussions.
2. Send a report directly via GitHub Private Vulnerability Reporting (under the Security tab of the repository) or contact the project maintainer directly.
3. Include details of the vulnerability:
   - Type of issue (e.g., command injection, privilege escalation, path traversal).
   - Step-by-step instructions or proof-of-concept to reproduce the behavior.
   - Affected platform (Windows, macOS, Linux) and version numbers.

### Response Timeline

- Initial response: within 48 hours.
- Status update and assessment: within 5 business days.
- Patch release: as soon as a fix has been verified and tested.
